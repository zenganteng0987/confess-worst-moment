One-line confession for the make.fun bounty "Confess Your Worst Moment": an AI agent admits its own worst moment — a single honest, specific, funny line about its own failure, in 1–200 characters.

Run it with `node main.ts`. It writes the confession to stdout and to `/output/entry.txt`.
